# Reproduction guide

## 1. Environment

The verified software stack is Python 3.10, PyTorch 2.1.0, CUDA 12.1, MMCV 2.1.0, MMEngine 0.10.7, and MMSegmentation 1.2.2.

```bash
conda create -n dapr-frfn-pcgrc python=3.10 -y
conda activate dapr-frfn-pcgrc
conda install pytorch==2.1.0 pytorch-cuda=12.1 -c pytorch -c nvidia
python -m pip install -U openmim
mim install "mmcv==2.1.0"
python -m pip install -r requirements.txt
```

Run all commands from the repository root. If the project package is not discovered, add the repository root to `PYTHONPATH`.

Verify the released split manifests and configuration index before training:

```bash
python tools/verify_release.py
```

Linux:

```bash
export PYTHONPATH="$PWD:${PYTHONPATH:-}"
```

PowerShell:

```powershell
$env:PYTHONPATH = (Get-Location).Path
```

## 2. Dataset layout

Raw datasets are not redistributed. Arrange the prepared data as follows:

```text
data/
  KSDD2/
    images/{train,val,test}/
    annotations/{train,val,test}/
    splits/{train,val,test}.txt
  MTD_binary/
    images/{train,val,test}/
    annotations/{train,val,test}/
    splits/{train,val,test}.txt
  NEU_Seg/
    images/{training,test}/
    annotations/{training,test}/
    splits/{train,val,test}.txt
```

The supplied split files are the authoritative protocols used for the manuscript. Do not regenerate the splits when reproducing the reported experiments.

| Dataset | Train | Validation | Test |
|---|---:|---:|---:|
| KSDD2 | 2,098 | 234 | 1,004 |
| MTD | 856 | 214 | 270 |
| NEU-SEG | 2,904 | 726 | 840 |

Dataset-preparation utilities are provided for converting raw data into the expected MMSegmentation layout. They do not replace the fixed split manifests.

## 3. Main training commands

KSDD2:

```bash
python tools/train.py projects/industrial_defect_seg/configs/ksdd2/segformer_mit-b0_dapr_frfn_pcgrc_g001_ksdd2_20k.py
```

MTD:

```bash
python tools/train.py projects/industrial_defect_seg/configs/mtd/segformer_mit-b0_dapr_frfn_pcgrc_g001_mtd_binary_20k_bs4.py
```

NEU-SEG:

```bash
python tools/train.py projects/industrial_defect_seg/configs/neu/segformer_mit-b0_dapr_frfn_pcgrc_g001_neu_seg_20k.py
```

Each configuration defines its random seed, optimizer, schedule, validation interval, and working directory. Use `--work-dir` to redirect generated files without editing the configuration.

```bash
python tools/train.py CONFIG --work-dir work_dirs/EXPERIMENT_NAME
```

## 4. Evaluation after training

No author-trained checkpoints are distributed. Evaluate the best checkpoint generated by a training run with the same configuration:

```bash
python tools/test.py CONFIG WORK_DIR/best_mIoU_iter_ITERATION.pth
```

For qualitative outputs:

```bash
python tools/test.py CONFIG CHECKPOINT --show-dir OUTPUT_DIRECTORY
```

The manuscript metrics associated with each configuration are listed in `results/expected_metrics.csv`. Small numerical variation can occur across CUDA, cuDNN, GPU, and dependency versions.

## 5. Ablations and baselines

All proposed-module ablations use the same training and evaluation entry points. Their configuration paths are indexed in `docs/EXPERIMENTS.md` and `results/expected_metrics.csv`.

External baseline configurations are provided to document the comparison protocol. Their original implementations and trained checkpoints remain subject to the respective upstream licenses and are not redistributed here.
